## 📧 Templates Universais

### Template 1: Pergunta Simples

**Melhor para:** Iniciar conversa sem pressão

```
Subject: Quick question {{firstName}}

━━━━━━━━━━━━━━━━━━━━━━━━━━

Oi {{firstName}},

Vi que {{company}} está [observação específica].

Empresas como [empresa similar] costumam ter
desafios com [dor específica].

Vocês também enfrentam isso?

[Seu Nome]
[Cargo]
[Empresa]

━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**Por que funciona:**
- ✅ Curto (50-70 palavras)
- ✅ Personalizado (observação específica)
- ✅ CTA simples (pergunta sim/não)
- ✅ Sem pitch agressivo

**Taxa de resposta esperada:** 8-12%

---

### Template 2: Case Study

**Melhor para:** Quando tem case relevante

```
Subject: Como [Cliente] conseguiu [Resultado]

━━━━━━━━━━━━━━━━━━━━━━━━━━

{{firstName}},

Semana passada ajudamos [Cliente Similar] a
[Resultado Específico] em [Tempo].

Vi que {{company}} tem [mesma dor/objetivo].

Posso mandar o case? Leva 2 minutos pra ler.

Abraço,
[Seu Nome]

P.S.: O case tem o passo a passo que usamos.

━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**Por que funciona:**
- ✅ Prova social imediata
- ✅ Resultado tangível
- ✅ Baixo comprometimento (só ler)

**Taxa de resposta esperada:** 10-15%

---

### Template 3: Problema Específico

**Melhor para:** ICP bem definido com dor clara

```
Subject: {{company}} + [sua solução]?

━━━━━━━━━━━━━━━━━━━━━━━━━━

Oi {{firstName}},

Notei que {{company}} está [contexto: crescendo/
contratando/expandindo].

Geralmente isso traz um desafio: [dor específica].

Ajudamos [segmento] a resolver isso com
[solução resumida].

Faz sentido conversarmos 15min?

[Seu Nome]

━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**Por que funciona:**
- ✅ Identifica dor específica
- ✅ Mostra que entende o contexto
- ✅ CTA direto

**Taxa de resposta esperada:** 7-10%

---

### Template 4: Valor Imediato

**Melhor para:** Quando pode oferecer algo de graça

```
Subject: Fiz isso pra você

━━━━━━━━━━━━━━━━━━━━━━━━━━

{{firstName}},

Passei 10min analisando {{company}} e identifiquei
3 oportunidades rápidas de [melhoria específica]:

1. [Quick win 1]
2. [Quick win 2]
3. [Quick win 3]

Quer a análise completa? É grátis e leva 5min
pra eu gravar.

Responde "sim" se quiser.

Abs,
[Seu Nome]

━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**Por que funciona:**
- ✅ Valor ANTES de pedir algo
- ✅ Mostra expertise
- ✅ Personalização extrema
- ✅ CTA ultra simples

**Taxa de resposta esperada:** 15-20%

**⚠️ Atenção:** Precisa realmente fazer a análise!

### Template 5: Breakup Email

**Melhor para:** Último email da sequência

```
Subject: Desisto (por enquanto)

━━━━━━━━━━━━━━━━━━━━━━━━━━

{{firstName}},

Essa é minha última tentativa de contato
(prometo! 😅).

Se não for o momento certo, sem problemas.

Mas se quiser ver como [resultado específico],
basta responder "sim".

Deal?

[Seu Nome]

P.S.: Se nunca for relevante, responde "não"
que paro de mandar.

━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**Por que funciona:**
- ✅ Tom humano e honesto
- ✅ Emoji humaniza
- ✅ Dá "última chance"
- ✅ Respeita o tempo do lead

**Taxa de resposta esperada:** 15-20% (!!)

## 📏 Regras de Ouro

### ✅ DO (Faça)

1. **Personalize** - Nome, empresa, observação específica
2. **Seja breve** - 50-100 palavras máximo
3. **Foque neles** - Não em você
4. **Uma pergunta** - CTA simples
5. **Use prova social** - Cases, números
6. **Seja humano** - Tom conversacional
7. **P.S.** - Reforça valor (opcional mas funciona)

### ❌ DON'T (Não faça)

1. **Anexos** - Vai direto pro spam
2. **Links demais** - Máximo 1-2
3. **Formatação complexa** - Sem cores/fontes
4. **Pitch agressivo** - Não venda no primeiro email
5. **"Dear Sir/Madam"** - Muito formal
6. **Mentiras** - Nunca invente dados
7. **Emojis demais** - Máximo 1-2 (ou nenhum)

## 🧪 A/B Testing

### Subject Lines para Testar

**Variação 1: Pergunta**
```
"Quick question {{firstName}}"
"{{firstName}} - pergunta rápida"
```

**Variação 2: Curiosidade**
```
"{{company}} + [sua empresa]?"
"Ideia para {{company}}"
```

**Variação 3: Valor**
```
"Fiz isso para você"
"3 oportunidades para {{company}}"
```

**Variação 4: Social Proof**
```
"Como [Cliente] conseguiu [Resultado]"
"[Cliente] fez isso ({{company}} pode também)"
```

### Email Body para Testar

**Versão A: Problema → Solução**
```
Problema + Como resolver
```

**Versão B: Case → Oferta**
```
Case study + Posso mostrar como?
```

**Versão C: Valor Imediato**
```
Oferta de análise/conteúdo grátis
```

## 📊 Métricas por Template

| Template | Open Rate | Reply Rate | Meeting Rate |
|----------|-----------|------------|--------------|
| Pergunta Simples | 45-55% | 8-12% | 2-3% |
| Case Study | 40-50% | 10-15% | 3-4% |
| Problema Específico | 50-60% | 7-10% | 2-3% |
| Valor Imediato | 55-65% | 15-20% | 5-7% |
| Breakup | 60-70% | 15-20% | 3-5% |

**Valor Imediato tem melhor performance**, mas exige mais trabalho (fazer análise de verdade).

## 🛠️ Funcionalidades Principais

### 1. Sequências de Email

**Setup de Campanha:**
```
Passo 1: Upload de lista (CSV)
Passo 2: Criar email template com variáveis
Passo 3: Definir delays entre emails
Passo 4: Ativar campanha
```

**Exemplo de Sequência:**
```
Dia 1: Email inicial
↓ (3 dias)
Dia 4: Follow-up 1
↓ (4 dias)
Dia 8: Follow-up 2 (case study)
↓ (5 dias)
Dia 13: Breakup email
```

**Variáveis disponíveis:**
- `{{firstName}}` - Nome
- `{{company}}` - Empresa
- `{{jobTitle}}` - Cargo
- `{{customVar1}}` - Qualquer campo customizado

---

### 2. Lemwarm (Warm-up Automático)

- Envia emails entre rede de usuários Lemlist
- Marca como não-spam
- Responde automaticamente
- Aumenta sender reputation

**Tempo de warm-up:** 2-4 semanas

**Sender Score ideal:** 80-100

## 🎯 Como Usar Lemlist (Passo a Passo)

### Setup Inicial (Dia 1-2)

**1. Domínio e Emails**
```
❌ NÃO use seu domínio principal (seusite.com)
✅ USE domínio secundário (mail.seusite.com ou tryseunome.com)

Compre 3-5 emails:
- nome1@mail.seusite.com
- nome2@mail.seusite.com
- nome3@mail.seusite.com
```

**2. Configurar DNS**
```
SPF, DKIM, DMARC corretamente configurados
(Lemlist tem guia passo a passo)
```

**3. Ativar Lemwarm**
```
Todas as contas em warm-up por 2-4 semanas
```

---

### Primeira Campanha (Semana 3)

**1. Construir Lista**
- 100-500 leads para teste
- Dados: Nome, Email, Empresa, Cargo
- Formato: CSV

**2. Criar Sequência**

**Email 1 (Inicial):**
```
Subject: Quick question about {{company}}

Hi {{firstName}},

Notei que {{company}} está [observação específica].

Empresas como [case similar] costumam ter desafios com [dor específica].

Vocês também enfrentam isso?

[Seu nome]
P.S.: Posso mandar um quick case de como resolvemos isso em 30 dias?
```

**Email 2 (Follow-up - 3 dias depois):**
```
Subject: Re: Quick question about {{company}}

{{firstName}},

Imaginei que você está ocupado.

Aqui está o case que mencionei: [link]

Vale 2 minutos do seu tempo?

[Seu nome]
```

**Email 3 (Breakup - 1 semana depois):**
```
Subject: Last one - Promise!

{{firstName}},

Vou parar de encher seu inbox depois dessa 😅

Se não for o momento, tudo bem!

Mas se quiser ver como [resultado específico], é só responder "sim".

Deal?

[Seu nome]
```

**3. Configurar Delays**
```
Email 1 → Email 2: 3 dias
Email 2 → Email 3: 7 dias
```

**4. Lançar Campanha**
```
Envios: 50 leads/dia (espalhar ao longo do dia)
```

---

### Otimização (Semana 4+)

**Monitorar:**
- Open rate: 40-60% ✅ | <40% ⚠️
- Reply rate: 5-15% ✅ | <5% ⚠️
- Bounce rate: <5% ✅ | >10% 🚨

**Se open rate baixo:**
- Testar subject lines diferentes
- Enviar em horários diferentes
- Verificar spam score

**Se reply rate baixo:**
- Melhorar copy (mais valor, menos pitch)
- Personalizar mais
- Ajustar ICP

## 🚀 Dicas Pro

### 1. Sender Reputation é Tudo
```
❌ NÃO envie 500 emails no dia 1
✅ Escale gradualmente:
   Semana 1: 20 emails/dia
   Semana 2: 50 emails/dia
   Semana 3: 100 emails/dia
   Semana 4+: 150-200 emails/dia por conta
```

### 2. Personalize Além do Nome
```
❌ "Oi {{firstName}}, tenho uma proposta"
✅ "Oi {{firstName}}, vi que {{company}} cresceu 30% esse ano (segundo LinkedIn). CMOs como você costumam..."
```

### 3. Breakup Email é Ouro
```
Emails 1-2: Taxa de resposta 5-8%
Email 3 (breakup): Taxa de resposta 15-20%

Pessoas respondem a "última chance"
```

### 4. Use Humor (com cuidado)
```
❌ "Dear Sir/Madam" (muito formal)
✅ "{{firstName}}, prometo que esse é meu último email (mentira, tenho mais 2 preparados 😅)"
```

### 5. Test, Test, Test
```
Sempre rode 2-3 variações de:
- Subject line
- Primeiro parágrafo
- CTA
```

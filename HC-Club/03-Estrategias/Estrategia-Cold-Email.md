## 🎯 O que é Cold Email?

**Cold Email** = Enviar email para alguém que **nunca ouviu falar de você**, oferecendo valor e buscando iniciar uma conversa.

**Não é:** Spam, email marketing em massa, comprar listas

**É:** Prospecção direcionada, personalizada, baseada em pesquisa

---

## 🔥 Por que Cold Email Funciona?

### Vantagens

✅ **Escalável:** 500-1.000 emails/dia com automação
✅ **Barato:** R$ 800-1.500/mês (ferramentas)
✅ **Rápido:** Primeiras reuniões em 7-14 dias
✅ **Mensurável:** Métricas claras (open, reply, meeting rate)
✅ **Direto:** Chega na inbox da pessoa certa

### Quando Usar

- ✅ B2B (funciona MUITO bem)
- ✅ Ticket médio >R$ 2.000
- ✅ ICP claro e grande (1.000+ empresas)
- ✅ Processo de venda consultivo

## 📋 Processo Completo (Passo a Passo)

### Fase 1: Preparação (Semana 1-2)

#### 1.1 Definir ICP

**ICP = Ideal Customer Profile**

Defina:
```
Indústria: SaaS, E-commerce, Serviços...
Tamanho: 10-50, 50-200, 200+ funcionários
Localização: Brasil, LatAm, Global...
Cargo: CEO, CTO, CFO, Head of Marketing...
Sinais de compra: Crescimento, funding, contratando...
```

**Guia:** [[Definir-ICP|Como Definir seu ICP Perfeito]]

---

#### 1.2 Setup Técnico

**Checklist:**
- [ ] Comprar domínio secundário
- [ ] Criar 3-5 emails
- [ ] Configurar SPF, DKIM, DMARC
- [ ] Ativar warm-up (2-4 semanas)
- [ ] Assinar ferramenta de automação
- [ ] Testar envio manual

**Tempo:** 2-3 dias

**Guia:** [[Setup-Tecnico|Setup Técnico Detalhado]]

---

#### 1.3 Construir Lista

**Onde encontrar leads:**

**Opção 1: Apollo.io (Free)**
1. Definir filtros (indústria, tamanho, cargo)
2. Exportar 100-500 leads
3. Verificar emails (Apollo já valida)

**Opção 2: Leads2b (Brasil)**
1. Buscar empresas por CNPJ
2. Enriquecer dados
3. Validar emails

**Opção 3: LinkedIn Sales Navigator + Export**
1. Buscar pessoas no LinkedIn
2. Usar ferramenta de scraping (Phantombuster)
3. Enriquecer emails (Hunter.io, Apollo)

**Opção 4: Manual**
1. Google: "CEO de [indústria] Brasil"
2. LinkedIn: Buscar e salvar perfis
3. Encontrar emails (Hunter.io, RocketReach)

**Tamanho ideal da lista:** 500-1.000 leads

**Formato CSV:**
```
firstName,lastName,email,company,jobTitle,customVariable
João,Silva,joao@empresa.com,Empresa XYZ,CEO,crescimento de 50%
```

---

#### 1.4 Criar Copy (Mensagens)

**Anatomia do Cold Email Perfeito:**

```
━━━━━━━━━━━━━━━━━━━━━━━━━━
1. SUBJECT LINE (curta, curiosidade)
━━━━━━━━━━━━━━━━━━━━━━━━━━

2. ABERTURA (personalizada, relevante)
   ↓
3. CREDIBILIDADE (prova social)
   ↓
4. VALOR (o que você resolve)
   ↓
5. CTA (call to action - simples)
   ↓
6. P.S. (opcional - reforça valor)
━━━━━━━━━━━━━━━━━━━━━━━━━━
```

**Exemplo Real:**

```
━━━━━━━━━━━━━━━━━━━━━━━━━━
Subject: Quick question João

━━━━━━━━━━━━━━━━━━━━━━━━━━
Oi João,

Vi que a Empresa XYZ cresceu 50% no último ano (parabéns!).

Empresas como [Case Similar] costumam ter um desafio:
escalar o time de vendas sem explodir o CAC.

Vocês também enfrentam isso?

Ajudamos empresas SaaS a reduzir CAC em 40% com
automação de prospecção.

Vale uma call de 15min?

Abs,
[Seu Nome]

P.S.: Posso mandar um case de como fizemos isso
com [Cliente Similar]?
━━━━━━━━━━━━━━━━━━━━━━━━━━
```

### Fase 2: Lançamento (Semana 3)

#### 2.1 Configurar Sequência

**Sequência Recomendada: 3-4 Emails**

```
┌─────────────────────────────────┐
│ EMAIL 1 (Dia 1) - Inicial       │
│ • Personalização + Valor        │
│ • CTA: Pergunta simples         │
└─────────────────────────────────┘
           ↓ 3 dias
┌─────────────────────────────────┐
│ EMAIL 2 (Dia 4) - Follow-up     │
│ • Case study ou prova social    │
│ • CTA: Call de 15min            │
└─────────────────────────────────┘
           ↓ 4 dias
┌─────────────────────────────────┐
│ EMAIL 3 (Dia 8) - Valor Extra   │
│ • Conteúdo útil (vídeo/artigo)  │
│ • CTA: Vale dar uma olhada?     │
└─────────────────────────────────┘
           ↓ 5 dias
┌─────────────────────────────────┐
│ EMAIL 4 (Dia 13) - Breakup      │
│ • "Última vez que encho saco"   │
│ • CTA: Responda "sim" ou "não"  │
└─────────────────────────────────┘
```

**Templates de cada email:** [[Templates-Cold-Email|Ver todos]]

---

#### 2.2 Lançar Campanha Piloto

**Estratégia Conservadora:**

```
Semana 1: 20 leads/dia (100 total)
Semana 2: 50 leads/dia (250 total)
Semana 3: 100 leads/dia (500 total)
```

**Por quê devagar?**
- Protege sender reputation
- Permite testar e iterar
- Evita spam complaints

**Horários de envio:**
```
Melhores horários (Brasil):
- 7h-9h (antes do trabalho)
- 11h-13h (pré-almoço)
- 15h-17h (meio da tarde)

❌ Evitar:
- Madrugada
- Final de semana
- Feriados
```

---

#### 2.3 Monitorar Métricas

**Primeiras 48h após envio:**

Abrir dashboard e verificar:

| Métrica | Ideal | Ação se Abaixo |
|---------|-------|----------------|
| Delivery Rate | >95% | Verificar bounce rate, limpar lista |
| Open Rate | 40-60% | Testar subject line |
| Reply Rate | 5-15% | Melhorar copy, ICP, personalização |
| Bounce Rate | <5% | Validar emails melhor |
| Spam Rate | <1% | ⚠️ PARAR campanha |

**Se Spam Rate >1%:**
```
🚨 AÇÃO IMEDIATA:
1. Pausar campanha
2. Revisar copy (muito agressivo?)
3. Revisar lista (ICP correto?)
4. Adicionar unsub link claro
5. Melhorar personalização
```

---

### Fase 3: Otimização (Semana 4+)

#### 3.1 A/B Testing

**Testar 1 variável por vez:**

**Teste 1: Subject Line (3 variações)**
```
A: "Quick question {{firstName}}"
B: "{{company}} + [Sua Empresa]?"
C: "Ideia para {{company}}"

Enviar 100 leads cada → Winner vai para resto
```

**Teste 2: Email Copy (2 variações)**
```
A: Foco no problema
B: Foco na solução

Enviar 150 leads cada → Winner escala
```

**Teste 3: CTA (2 variações)**
```
A: "Vale uma call de 15min?"
B: "Responde 'sim' se fizer sentido"

Enviar 150 leads cada
```

---

#### 3.2 Analisar Respostas

**Categorizar respostas:**

```
✅ Positivas (Interessado):
   → Mover para "Qualificação"
   → Responder em <2h
   → Agendar reunião

🤔 Neutras (Talvez):
   → Mover para "Nurturing"
   → Follow-up em 2 semanas

❌ Negativas (Não interessado):
   → Perguntar "Quando seria bom momento?"
   → Adicionar em campanha futura (3-6 meses)

😡 Raiva/Reclamação:
   → Remover da lista
   → Desculpar-se
   → Ajustar messaging
```

**Objeções comuns e respostas:**

| Objeção | Resposta |
|---------|----------|
| "Não tenho tempo" | "Entendo! Posso mandar material rápido (2min)?" |
| "Já temos solução" | "Ótimo! Sempre vale benchmark. Posso mandar case?" |
| "Sem budget" | "Quando revisam orçamento? Posso te marcar para [mês]?" |
| "Não sou decisor" | "Quem seria a pessoa certa? Posso mencionar você?" |

---

#### 3.3 Escalar o que Funciona

**Quando escalar:**
```
✅ Open rate >40%
✅ Reply rate >5%
✅ Bounce rate <5%
✅ Spam complaints <0.5%
```

**Como escalar:**
```
Fase 1: 100 leads/dia (1 conta)
   ↓ 2 semanas
Fase 2: 300 leads/dia (3 contas)
   ↓ 1 mês
Fase 3: 500 leads/dia (5 contas)
```

**Limite máximo:**
- 150-200 emails/dia por conta
- 5-10 contas no máximo

## ⚠️ Erros Comuns (e Como Evitar)

### ❌ Erro 1: Usar Domínio Principal

**Problema:** Se queimar reputação, afeta todos os emails da empresa

**Solução:**
```
❌ vendas@suaempresa.com
✅ nome@mail.suaempresa.com
```

---

### ❌ Erro 2: Zero Personalização

**Problema:**
```
"Olá,

Temos uma solução incrível para sua empresa.

Quer saber mais?"
```

**Solução:**
```
"Oi {{firstName}},

Vi que {{company}} [observação específica sobre eles].

Empresas como [case] costumam ter [dor].

Vocês também?"
```

---

### ❌ Erro 3: Pitch Imediato

**Problema:**
```
"Somos a melhor empresa de X no Brasil.
Temos 10 anos de experiência, 50 clientes..."
```

**Solução:**
```
Falar sobre ELES, não sobre você.
Valor primeiro, pitch depois (na reunião).
```

---

### ❌ Erro 4: CTA Complexo

**Problema:**
```
"Gostaria de agendar uma reunião para discutir
como podemos implementar nossa solução na sua empresa?"
```

**Solução:**
```
"Vale uma call de 15min?"
ou
"Responde 'sim' se fizer sentido?"
```

---

### ❌ Erro 5: Desistir Cedo

**Problema:**
```
Envia 1 email → Sem resposta → Desiste
```

**Solução:**
```
80% das vendas acontecem entre o 5º e 12º follow-up.

Envie 3-4 emails mínimo.
Breakup email tem 15-20% de reply rate!
```

## 🛡️ Compliance e LGPD

### É Legal Cold Email no Brasil?

**SIM**, desde que:

✅ Seja B2B (email corporativo)
✅ Tenha opt-out claro
✅ Não seja spam (relevante e personalizado)
✅ Respeite pedidos de remoção

❌ **NÃO envie** para emails pessoais (@gmail, @hotmail)

**Guia completo:** [[Compliance-LGPD|LGPD e Cold Email]]

---

### Opt-out Obrigatório

**Adicione no final de TODOS os emails:**

```
━━━━━━━━━━━━━━━━━━━━━━━━━━
Se não quiser receber mais emails,
basta responder "remover".
━━━━━━━━━━━━━━━━━━━━━━━━━━
```

ou

```
━━━━━━━━━━━━━━━━━━━━━━━━━━
Não é pra você? [Clique aqui para sair]
━━━━━━━━━━━━━━━━━━━━━━━━━━
```

## 💡 Dicas Finais (Pro)

### 1. Follow-up é Onde Está o Ouro
```
Email 1: 3-5% reply
Email 2: +2-3% reply
Email 3: +1-2% reply
Email 4 (breakup): +5-8% reply

Total: 11-18% reply rate
```

### 2. Personalize o Máximo Possível
```
Nível 1: Nome + Empresa
Nível 2: + Cargo + Localização
Nível 3: + Observação específica sobre empresa
Nível 4: + Referência a post/notícia sobre eles
Nível 5: + Vídeo/imagem personalizada
```

### 3. Timing é Tudo
```
Terça, Quarta, Quinta: +20% reply rate vs Segunda/Sexta
7-9h e 15-17h: Melhores horários
Fim de mês: Decisores mais receptivos
```

### 4. Use Social Proof
```
"Ajudamos [Cliente Similar] a [Resultado]"
→ +40% credibilidade
```

### 5. CTA Simples
```
❌ "Gostaria de agendar..."
✅ "Vale 15min?"
✅ "Posso mandar o case?"
✅ "Responde 'sim' se fizer sentido"
```
